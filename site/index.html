画像のモザイク範囲を検出・編集・保存

Mozarieは、PNG・JPEG・WebP画像のモザイク範囲をWindows上でローカル検出し、確認・編集・保存できるアプリです。

最新版をダウンロードREADMEを読む

Windows / PNG・JPEG・WebP / MIT License

検出から保存まで

画像を読み込み、候補を検出

PNG・JPEG・WebP画像やフォルダーを読み込み、現在の画像または全画像からモザイク候補を検出できます。

SAMによる輪郭補正や、検出した手の領域の除外に対応しています。

範囲を見て、手描きで調整

候補を確認し、除外・削除できます。モザイク・除外ブラシ、消しゴム、境界ツールで範囲を調整できます。

強制除外を優先し、Undo / Redoで編集を戻したりやり直したりできます。

複数画像の作業を整理

PJごとに管理し、確認済み・未確認、モザイクの有無で絞り込めます。

非表示にしたデータは保持して再表示でき、全画像検出・保存・マスク出力の対象から除外できます。

保存対象と出力を選択

現在の画像、モザイクのある画像、確認済み画像を選び、コピー保存または元画像へ上書きできます。

モザイクの粗さ、形式、メタデータの保持を選べます。

使い始めるまで

Windowsと64-bit Python（Python Launcher py）を用意します。NVIDIA/CUDAはPython 3.11〜3.14、AMD/DirectMLとCPUは3.11または3.12に対応しています。

  1. 最新ReleaseのZIPを展開します。
  2. setup.bat を実行して、使用する環境をセットアップします。
  3. run.bat で起動し、設定 > 検出から基本モデルを指定します。

検出・編集・保存はPC上で行います。モデルの取得やアプリの更新にはネットワーク接続が必要です。基本モデルは別途用意します。必要なモデル、補助モデルの配布条件、変換手順はREADMEのモデル説明を確認してください。

更新は設定の更新を確認、またはupdate.batから行います。適用前にMozarieを終了し、失敗した場合は同じReleaseのupdate.batをもう一度実行します。

よくある質問

検出候補は、そのまま保存できますか？
候補は確認して必要に応じて修正してください。検出後もブラシや境界ツールで範囲を調整できます。
コピー保存で元画像は変わりますか？
元画像を残すにはコピー保存を選び、「コピー成功後に元画像を削除」をオフにしてください。元画像を変更する場合は上書きを選びます。
GPUで失敗したらCPUへ自動で切り替わりますか？
CPUでも利用できますが、GPUで失敗しても自動ではCPUへ再試行しません。設定からCPUへ手動で切り替えてください。
モデルはアプリに含まれますか？
基本モデルは別途選んで取得します。補助モデルを含む配布元の条件とライセンスは、各配布元と第三者ライセンス・モデル配布元を確認してください。
