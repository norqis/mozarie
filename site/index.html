モザイク加工を、検出から仕上げまで

Mozarieは、モザイクをかける場所の自動検出から、手描きでの調整、複数画像の確認、保存まで行えるWindowsアプリです。

最新版をダウンロード詳しい使い方

Windows / PNG・JPEG・WebP / MIT License

モザイク加工を、ひとつの作業画面で

検出した候補を出発点に、画像を見ながら範囲を整えます。一枚の仕上げも、フォルダーにまとめた画像の確認も、Mozarieで進められます。

モザイクをかける場所を見つける

読み込んだ画像から、モザイクをかける範囲の候補を自動検出できます。一枚ずつの検出に加え、フォルダー内の画像をまとめて検出し、候補を確認しながら作業を進められます。

必要な部分を、ブラシで仕上げる

検出した範囲を画像に重ねて確認し、足りない部分を描き足したり、残したい部分を除外したりできます。ブラシや消しゴム、境界の調整を使い、画像ごとにモザイクの範囲を整えられます。

編集は元に戻したり、やり直したりできるので、範囲を見比べながら仕上げられます。

複数画像の確認を、整理しながら

画像をプロジェクトにまとめ、確認済み・未確認で絞り込めます。まだ見ていない画像やモザイクのある画像を一覧で探し、次に確認する画像を選べます。

今回の作業に使わない画像は非表示にしておけます。編集内容は保持され、再表示すると続きから作業できます。

用途に合わせて、保存する

モザイクの粗さや保存形式を選び、仕上げた画像を書き出せます。現在の一枚だけでなく、モザイクのある画像や確認済みの画像をまとめて保存できます。

別のファイルへのコピー保存と元画像への上書きに対応し、メタデータを保持するかどうかも選べます。

画像の検出・編集・保存はローカルで

検出・編集・保存は、WindowsのPC上で行います。PNG・JPEG・WebPに対応しています。
