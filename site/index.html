モザイク加工を、検出から仕上げまで

自動検出と手描きで範囲を整え、画像を確認して保存するWindowsアプリです。

最新版をダウンロード詳しい使い方

Windows / PNG・JPEG・WebP / MIT License

比べて仕上げる

編集結果と適用範囲を並べて、モザイクのかかる場所を確認できます。

手描きで、細部まで

ブラシと消しゴムで、かけたい範囲と残したい部分を整えられます。

複数画像を、まとめて

フィルターで確認する画像を絞り、編集した画像をまとめて保存できます。

画像の加工は、PC上で

検出・編集・保存はWindowsのPC上で行います。
