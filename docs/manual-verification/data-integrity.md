# データ整合性の実環境確認

決定的に再現できる契約は `tests/verification-contracts.data-integrity.json` に移行した。
ここには入力機器とランタイムのメモリ回収に依存し、CIで同じ観測を再現できない項目だけを残す。

| 観測キー | 期待値 | 実環境 | CIで再現できない理由 |
| --- | --- | --- | --- |
| DI-080.1 | 保存終了後に出力全件分の画像バッファを保持せず、完了回数に応じて待機時RAMが増え続けない | 実ブラウザー、4K画像一式、OSのプロセスメモリ計測 | 保存完了後の待機時RAMはランタイムとOSの回収時期に依存し、CIで安定した合否にできないため |
| DI-082.1 | マウスを離す前からモザイクが追従し、操作時間に応じて追従遅延が増えない | 実ブラウザー、実ポインティングデバイス、4K表示 | 連続ドラッグの知覚遅延は入力機器、表示更新頻度、GPU構成に依存するため |
| DI-101.2 | 候補数に比例して処理中のRAMが増え続けない | 実ブラウザー、4K候補多数、OSのプロセスメモリ計測 | 候補数増加時の実RAM推移はブラウザーとOSの回収時期に依存するため |
| DI-107.3 | 処理中のRAMが画像数や出力時間に比例して増え続けない | 実データ、大規模PJ、OSのプロセスメモリ計測 | 実RAMの推移はOSとPythonのメモリ回収時期に依存するため |
