# 通信・対象の組合せ・PJデータ照合

[共通確認](../manual-verification.md)を全行で実施する。OS選択ダイアログは開かない。

## 対象の準備

A～Hは確認用画像を区別する記号。ファイル名は任意とし、各記号と実ファイル名を対応させる。パス入力で読み込み、名前付き・作業中PJとして保存する。別PJには別の画像と編集を用意する。

| 画像 | モザイク | 確認状態 | 表示状態 |
| --- | --- | --- | --- |
| A | あり | 確認済み | 表示 |
| B | あり | 未確認 | 表示 |
| C | なし | 確認済み | 表示 |
| D | なし | 未確認 | 表示 |
| E | あり | 確認済み | 非表示 |
| F | あり | 未確認 | 非表示 |
| G | なし | 確認済み | 非表示 |
| H | なし | 未確認 | 非表示 |

モザイクありは有効な範囲が残る状態にする。保存比較には各画像の未加工コピーを別に保持する。上書き確認は確認用画像だけで行う。
