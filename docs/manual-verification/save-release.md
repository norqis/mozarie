# 保存・書き出し・異常時・リリース

[共通確認](../manual-verification.md)を全行で実施する。故障・削除・上書きの確認は専用コピー上で行う。

コピー保存は保存先が設定済みかつ書き込み許可済みの場合だけ実施する。保存先の選択・変更、Windowsダイアログでの許可・取消は実施しない。ダウンロードは保存先を尋ねないブラウザー設定の場合だけ実施する。
