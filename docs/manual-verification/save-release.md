# 保存・書き出し・異常時・リリース

[共通確認](../manual-verification.md)を全行で実施する。故障・削除・上書きの確認は専用コピー上で行う。

コピー保存は保存先が設定済みかつ書き込み許可済みの場合だけ実施する。保存先の選択・変更、Windowsダイアログでの許可・取消は実施しない。ダウンロードは保存先を尋ねないブラウザー設定の場合だけ実施する。

| ID | 手順 | 期待値 |
| --- | --- | --- |
| SV-001 | 単一ファイル保存を開く | 現在画像名を表示し、対象を絞るプルダウンは出さない |
| SV-002 | 単一保存の末尾を空欄にする | 空欄を許可し、必須入力エラーを出さない |
| SV-003 | 単一保存で末尾を入力後に空へ戻し、入力欄からフォーカスを外す | 末尾が空のまま残る |
| SV-004 | 単一保存を閉じて一括保存を開く | 単一の空末尾を一括へ流用せず、一括の既定末尾を表示する |
| SV-005 | 保存形式「元形式」で、設定済み保存先に同名ファイルがない状態で単一コピー保存 | 元名と同じ拡張子で現在画像1件だけを保存する |
| SV-006 | 設定済み保存先に同名ファイルがある状態で単一コピー保存 | 既存ファイルを保持し、連番名で保存する |
| SV-007 | 単一保存に末尾文字列を指定 | 拡張子の前へ指定文字列を追加する |
| SV-009 | 単一保存の閉じるを押す | ファイルを出力せず編集画面へ戻る |
| SV-010 | 単一上書きの確認を3秒以上表示してから取消 | 取消ボタンが操作でき、元画像の内容と更新時刻を変えず保存画面へ戻る |
| SV-011 | 単一上書きの確認を3秒以上表示してから確定 | 実行ボタンが操作でき、指定画像だけを保存内容で置き換える |
| SV-012 | 単一コピー後元画像削除の確認を3秒以上表示してから確定 | 実行ボタンが操作でき、コピーの成功後にだけ元画像を削除する |
| SV-013 | 単一保存後の候補と画像一覧を見る | 候補・マスク・確認済み・非表示・一覧画像を保持する |
| SV-014 | 保存直後に同じ画像を再保存 | 前回の出力済み状態で除外せず、もう一度保存できる |
| SV-015 | 一括保存を開く | 保存対象の選択と件数を表示する |
| SV-016 | 一括保存対象をすべてにする | 一覧の対象全件を含み、以前保存した画像も含む |
| SV-017 | 一括保存対象をモザイクありにする | モザイクのある画像だけを数え、同じ対象を保存する |
| SV-018 | 一括保存対象を確認済みにする | 確認済み画像だけを数え、出力済みでも除外しない |
| SV-019 | 確認済み400画像を対象に一括保存 | 件数が400となり、400画像を出力する |
| SV-020 | 一括コピー保存 | 対象画像をそれぞれ出力し、元画像を保持する |
| SV-021 | 一括上書きの確認を3秒以上表示してから確定 | 実行ボタンが操作でき、対象画像だけを上書きし、対象外の元画像を保持する |
| SV-022 | 一括保存の末尾を空にして開始 | 空欄を許容し、同名競合時は連番にする |
| SV-023 | 一括保存の粗さを変更 | 指定粒度で出力し、候補マスクの形状は変わらない |
| SV-025 | 一括保存を一時停止 | 進行中の処理が落ち着いた後に新規出力を開始しない |
| SV-026 | 一括保存を再開 | 未処理画像を保存し、完了済み画像を重複出力しない |
| SV-027 | 一括保存をキャンセル | 未処理分を成功扱いにせず、操作を再有効化する |
| SV-028 | 一括保存完了後の一覧と候補を見る | 対象画像と編集データが残る。保存で一覧削除を行うチェック欄は存在しない |
| SV-029 | 元形式で保存したPNGを開く | 寸法・形式を保持し、モザイク範囲に加工を反映する |
| SV-030 | 元形式で保存したJPEGを開く | 寸法を保持し、編集画面と同じ向きのJPEGとして開ける |
| SV-031 | 元形式で保存したWebPを開く | WebPとして開け、モザイク範囲が反映される |
| SV-032 | 透過PNGを保存して開く | 透過部分を保持し、加工対象以外の透過を塗りつぶさない |
| SV-033 | parametersテキストを含むPNGをメタ情報保持ONで上書き保存し、保存前後のテキストを比較 | parametersの文字列が一致し、画像を開ける |
| SV-034 | 除外とモザイクが重なる画像を保存 | 除外後の合成範囲だけにモザイクがかかる |
| SV-035 | モザイク範囲なしの画像を保存 | 加工なしの画像を出力し、一覧から外さない |
| SV-036 | 現在画像のモザイク範囲を保存 | 元画像寸法のPNGで、除外を差し引いた範囲を出力する |
| SV-037 | 現在画像の除外範囲を保存 | 元画像寸法のPNGで、除外範囲を出力する |
| SV-038 | 候補枠ありで単体範囲を保存 | 指定した枠の拡張を含む範囲を出力する |
| SV-039 | PJ行のモザイクZIPを保存 | そのPJの各画像のモザイク範囲をZIPに含める |
| SV-040 | PJ行の除外ZIPを保存 | そのPJの各画像の除外範囲をZIPに含める |
| SV-041 | 別PJ行からZIPを保存 | 現在PJを切り替えず、指定行のPJだけを出力する |
| SV-042 | 編集中PJ行からZIPを保存 | 直前の候補編集もZIPに反映する |
| SV-043 | 完了PJ行からZIPを保存 | 閲覧専用を維持したまま保存できる |
| SV-044 | 画像0件のPJ行を見る | 2種類のZIP操作だけ無効となり、PJを開く・削除は操作できる |
| SV-045 | PJ管理を開き、開発者ツールのNetworkをOfflineにして行のモザイクZIPを押す。Onlineへ戻す | 通信エラーを表示し、PJ管理表と対象PJを保持する。再度ZIPを保存できる |
| SV-046 | 設定済み保存先に書き込めなくなった状態で保存 | 書き込み失敗を示し、保存完了を表示しない。元画像を削除しない。アクセス許可を求めるOS操作は実施しない |
| SV-047 | 読み込み後に元画像を変更して保存 | 元画像変更を案内し、無確認で上書きしない |
| SV-048 | 読み込み後に元画像を削除して保存 | 対象画像の不足を案内し、別画像の不具合と表示しない |
| SV-050 | 保存開始後に開発者ツールのNetworkをOfflineにし、エラー後Onlineへ戻す | 未取得の保存結果を成功表示しない。再接続後はサーバーの進捗を表示する |
| SV-051 | 開発者ツールのNetworkをOfflineにしてPJ管理を開き、Onlineへ戻す | 通信エラーを表示し、現在の作業画面を維持する |
| SV-052 | PJ管理を開いてNetworkをOfflineにし、名前ヘッダーを押してOnlineへ戻す | 通信エラーを表示し、取得済みの行順と昇降順表示を保持する |
| SV-053 | PJ削除確認を開いてNetworkをOfflineにし、削除を確定してOnlineへ戻す | 通信エラーを表示し、対象PJと現在の編集を保持する |
| SV-054 | PJ名を入力してNetworkをOfflineにし、保存を押してOnlineへ戻す | 通信エラーを表示し、保存前のPJ名・候補・手描き・確認状態を保持する |
| SV-055 | 一覧クリア確認を開いてNetworkをOfflineにし、確定してOnlineへ戻す | 削除成功と表示せず、一覧とPJを保持する |
| SV-056 | エラー画面を閉じる | 元の画面へ戻り、実行中でない操作を再び使える |
| SV-057 | 4K画像で描画→Undo→Redoを5回 | 描画がリアルタイムで反映され、履歴回数に応じて応答が鈍化し続けない |
| SV-058 | 400画像の検索・一覧切替を5回 | DOMとメモリが繰り返しで増え続けず、全件の画像本体を再取得し続けない |

| SV-065 | update.batで更新 | 更新後のVERSIONがリリースと一致し、設定とPJデータを保持する |
| SV-066 | PRとリリースを開く | PRと説明は日本語、リリース名はバージョンだけ。説明は変更内容を簡潔に記載する |
