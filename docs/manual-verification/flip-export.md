# 画像反転・保存形式・メタ情報

[共通確認](../manual-verification.md)を全行で実施する。1920×960、確認専用の画像コピーとPJを使う。

上下左右を識別できる画像、透過PNG、文字情報入りPNG、EXIF・ICC付きJPEG、メタ情報入りWebPを用意する。PNGの文字情報は `parameters`・`prompt`・`workflow` に異なる文字列を入れる。出力は画像表示と形式・拡張子・Content-Type・メタ情報の内容を照合する。メタ情報OFFでは元画像由来の情報を引き継がないことを見る。JPEGエンコーダーが生成するJFIF等は除去対象に含めない。Windowsダイアログを開く操作は行わない。

## 反転

| --- | --- | --- |

| FE-003 | 左右反転をもう一度押す | 元の向きに戻る |
| FE-004 | 画像を選んで上下反転を押す | 画像の上端と下端が入れ替わり、左右の位置と寸法は変わらない |
| FE-005 | 上下反転をもう一度押す | 元の向きに戻る |
| FE-006 | 左右反転の後に上下反転を押す | 元画像の左上が右下、右上が左下へ移る |
| FE-007 | モザイクのある画像を左右反転 | 元の加工対象と一緒にモザイクが左右反転する |
| FE-008 | 除外のある画像を上下反転 | 元の対象と一緒に除外が上下反転する |
| FE-009 | 左右反転後にモザイク筆で描く | ポインターのある位置にモザイクを追加する |
| FE-010 | 上下反転後に除外筆で描く | ポインターのある位置に除外を追加し、モザイク手描きは追加しない |
| FE-011 | 左右反転後にモザイク消しゴムを使う | ポインター位置のモザイク手描きだけを消す |
| FE-012 | 上下反転後に除外消しゴムを使う | ポインター位置の除外を消す |
| FE-013 | 左右反転後にモザイク塗りつぶしを使う | 押した位置の色を起点としてモザイク範囲を追加する |
| FE-014 | 上下反転後に除外塗りつぶしを使う | 押した位置の色を起点として除外範囲を追加する |
| FE-015 | 左右反転後に境界を指定 | 表示中の指定位置を対象とし、左右反対の位置を処理しない |

| FE-017 | 2枚表示で上下反転 | 左の画像と右の範囲を同じ向きに反転する |
| FE-018 | 反転後にズームしてパンする | 画像と範囲が同じ座標を維持し、左右の画面が同期する |
| FE-019 | 反転直後にUndo | 反転前の向きへ戻り、範囲と画像の位置関係を保持する |
| FE-020 | 反転のUndo後にRedo | 反転後の向きを再適用する |
| FE-021 | Aだけを反転しBへ移動してAへ戻る | Aの向きを保持し、Bの向きは変わらない |
| FE-022 | PJを閉じて再開する | 各画像の反転状態を復元する |
| FE-023 | 完了PJの画像を開く | 反転状態を表示するが、反転操作はできない |
| FE-024 | 反転だけを行った画像の単一保存を開く | モザイク範囲がなくても保存操作が可能 |
| FE-025 | 反転画像を元形式・保持ONでコピー保存する | 出力を反転した向きで保存し、元画像ファイルを変えない |
| FE-026 | 反転画像を元形式・保持ONで上書き保存して再表示する | 出力と編集画面の向きが一致し、反転を二重適用しない |
| FE-027 | 上書き後にもう一度保存する | 向きが再び逆にならない |
| FE-028 | 左右・上下・両方・反転なしの4画像を元形式・保持ONで一括保存 | 各画像の向きをそれぞれ出力へ反映する |
| FE-029 | 反転画像のモザイク範囲PNGを保存する | 保存画像と同じ向きで除外差引き後の範囲を出力する |
| FE-030 | 反転画像の除外範囲PNGを保存する | 保存画像と同じ向きで除外範囲を出力する |
| FE-031 | 4K画像で左右反転を10回行う | 最後は元の向き。反転ごとの全画素コピーを履歴へ蓄積せず、操作回数に応じて待機時RAMが増え続けない |
