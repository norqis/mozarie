# 画像反転・保存形式・メタ情報

決定的に再現できる画素、形式、メタ情報、状態遷移、失敗復旧は自動テストへ移した。ここには実フォント、DPI、実モデル、OSのメモリ挙動が必要な観測だけを残す。Windowsダイアログを開く操作は行わない。

| ID | 実環境 | 手順 | 期待値 |
| --- | --- | --- | --- |
| FE-001 | 実ブラウザーを表示したWindowsデスクトップ | 画像未選択で上部ツールを見る | 左右反転・上下反転が他のボタンや文字と重ならない |
| FE-031 | 4K画像を扱える実Windowsプロセスとタスクマネージャー | 4K画像で左右反転を10回行い、操作後の待機時RAMを観測する | 反転ごとの全画素コピーを履歴へ蓄積せず、操作回数に応じて待機時RAMが増え続けない |
| FE-032 | 実ブラウザーを表示したWindowsデスクトップ | 単一保存を開く | 現在画像名と保存形式・メタ情報保持の各欄が重ならない |
| FE-053 | 4K画像を繰り返し変換できる実Windowsプロセスとタスクマネージャー | 4K画像の形式変換保存を5回行い、完了後の待機時RAMを観測する | 全出力分のデコード画像・バッファを保持せず、回数に応じたRAM増加が続かない |
| FE-077 | 配布対象の実検出モデルと利用可能なCPUまたはGPU | 反転上書き後に自動検出する | 元座標へ戻して実モデルで処理し、得られた候補を表示中の向きで重ねる。検出精度の良否は判定しない |
| FE-086 | 実ブラウザーを表示したWindowsデスクトップ | PNG画像の保存でJPGを選ぶ | メタ情報を保持しない警告と無効な保持欄の文字が切れない |
